## v1.3.6a Hebrew weak-verb source map

The normalized registry is recognition-focused: a chart is complete for the rows it names, but the milestone does not claim every weak class in every stem and form. Gesenius' starred and bracketed variants are not silently combined with the main forms.

## v1.3.7 Grammar Handbook source map

Source roles are intentionally separate. **MB** is Merkle and Plummer, *Beginning with New Testament Greek* (B&H Academic, first ed., 2020); **MGD** is Köstenberger, Merkle, and Plummer, *Going Deeper with New Testament Greek* (B&H Academic, first ed., 2016); **MEG** is Merkle, *Exegetical Gems from Biblical Greek* (Baker Academic, first ed., 2019). These sources guide Greek organization, terminology, and selective intermediate emphasis. **BBH** is Pratico and Van Pelt, *Basics of Biblical Hebrew Grammar* (Zondervan Academic, 3rd ed., 2019); it guides Hebrew organization and visible terminology. **Machen** is the approved 1923 first edition and **GKC** is the approved 1910 second English edition; they support the exact foundational content locations below. **App** means a v1.3.7 reading workflow, recognition sequence, or ambiguity warning synthesized for this application rather than quoted from one book.

The runtime registry in `src/features/grammar/handbook-data.js` is canonical and records these roles per article. “Partial” means the cited source supports the named foundational claim or form family but not every editorial sentence. No Merkle, Pratico, or Van Pelt work is represented as the row source for an existing paradigm.
