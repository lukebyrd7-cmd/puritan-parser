# v1.9.2 — Greek Vocabulary Audit

## Scope and source boundary

This release audits all 5,478 stable Greek vocabulary identities represented by 19,049 form rows and all 6,068 numbered entries in James Swanson, *Dictionary of Biblical Languages with Semantic Domains: Greek (New Testament)*.

Swanson was used privately as verification-only. It identified mapping and gloss-review candidates, but its transcription and definitions are not committed, imported into runtime data, or reproduced in the sanitized audit. Shipped wording is limited to the existing CC0 Puritan Parser Greek gloss source. MorphGNT SBLGNT remains authoritative for the canonical corpus lemma, morphology, part of speech, and frequency.

The deterministic sanitized result is `audits/v1.9.2-greek-vocabulary-audit.json`. It contains stable IDs, headwords, Strong associations reported by the verification source, mapping/classification facts, concise reasons, and summary counts. It has no dictionary-definition field.

| Standard lexical gloss | `data/glosses/greek-glosses.json`, merged by exact language + lemma |
| Effective standard gloss | `src/models/gloss.js`; one resolver applies source presentation and the stable-ID correction manifest |
| Corrections | `data/glosses/corrections.json`, guarded by expected source value and independent approved support |
| Personal Standard/Add/Use behavior | `src/models/personal-glosses.js` layered after the corrected standard presentation |
| Search | The shared effective gloss contributes display and indexed search text; stable lexical identity remains unchanged |
| Learn, Daily Practice, English-first, Custom Decks, Needs attention | Shared study entries and `getDisplayGloss`; occurrence data is not a card answer |
| Reader Word Details and Word Page | Shared lexical resolver; occurrence-specific help is a separate Reader-only field |
| Greek contextual gloss | No Greek Reader chapter currently contains an occurrence/contextual English gloss field |

No parallel Greek lexicon or runtime Swanson parser was introduced. The audit parser is development-only.

## Greek text in English gloss fields

### Root cause

The Greek gloss generator historically populated 3,699 low-frequency lemma records with the Greek lemma itself when it had no trusted English gloss. Both `primaryGloss` and generated legacy `gloss` then contained Greek. The shared gloss resolver validated only non-emptiness, so Reader Word Details and every other standard-gloss consumer accepted the Greek fallback as if it were English.

This affected:

- 3,699 of 5,478 stable Greek identities;
- 7,896 of 137,554 Greek Reader tokens (5.74%);
- the standard lexical `primaryGloss`/legacy `gloss` path used by Reader, Learn, English-first practice, Word Page, Search, Custom Decks, and Needs attention.

The highest-frequency affected identity occurs 18 times; the defect is concentrated in lower-frequency vocabulary, including both ordinary lexemes and proper names.

Every affected source record has the same cause: its `primaryGloss` is exactly its canonical Greek lemma and it has no alternate gloss. The cause breakdown is therefore 3,699 missing-English lemma fallbacks, with zero surface-form, transliteration, malformed-source, contextual-promotion, or other cases.

### Correction

The authoritative shared presentation resolver now accepts only learner-facing English in standard gloss fields. Greek script, Hebrew script, morphology codes, Strong identifiers, lexical IDs, numeric values, and other non-English fallback metadata are rejected. When no trusted English remains, consumers receive an explicit unavailable presentation (`Gloss unavailable` in Reader and the existing missing-gloss state in card eligibility) instead of Greek masquerading as English.

The unified practice eligibility boundary uses the same learner-English validation before constructing Daily Practice, English-first, Custom Deck, or Needs-attention cards. Exhaustive acceptance validation retained all 1,779 trustworthy Greek identities and excluded exactly the 3,699 unavailable identities; no Greek-script card answer remained eligible.

All 3,699 contaminated identities were systematically checked against this failure pattern. All 7,896 affected Reader tokens now resolve without Greek in the English gloss output. Hebrew uses the same guard, so the equivalent fallback pattern cannot silently render Hebrew script as English; its existing source coverage and explicit unavailable record remain unchanged.

## Greek English Gloss Coverage

This acceptance pass traced every unavailable identity through all approved, distributable Greek assets already recorded in the project source ledger. `data/glosses/greek-glosses.json` and its generated `vocab_all.json` rows contain only the Greek lemma fallback for these identities. MorphGNT and the Greek Reader/search assets contain lemma, form, morphology, POS, frequency, and location but no lexical English field. The correction manifest contains no applicable alternative. WEB/OEB verse translations and Reference examples are not lexical sources and were not promoted into vocabulary data. There is no alternate Strong field or second checked-in Greek lexicon available to the merge.

No gloss was recovered in this pass. That is a source-boundary result, not an assertion that these lexemes lack English meanings. Swanson verifies that many need real lexical glosses, but it cannot authorize distributed wording.

## Contextual gloss behavior and metrics

The lexical gloss remains the primary learner meaning. Reader contextual help now appears only when the centralized conservative comparison finds at least one English sense not already represented by the lexical senses. Comparison ignores capitalization, punctuation, leading articles, trivial plural differences, sense order, and exact contained senses. When retained it is visually secondary and labeled **In this verse**. It never enters Search identity, flashcard prompts, mastery, SRS, personal gloss storage, or stable IDs.

Greek corpus measurements:

| --- | ---: | ---: |
| Total Greek Reader tokens | 137,554 | 100.00% |
| Tokens with contextual gloss data | 0 | 0.00% |

| Meaningfully different / retained contextual glosses | 0 | 0.00% |
| Malformed contextual glosses | 0 | 0.00% |
| Greek-script contextual values | 0 | 0.00% |
| Tokens without contextual gloss data | 137,554 | 100.00% |

The requested 20 hidden and 20 retained Greek occurrence samples do not exist in the current dataset, so sample review is not applicable. Deterministic fixtures cover both suppression and retention behavior for future occurrence data. Contextual data was not invented merely to populate the metric.

Accordingly, no current Greek Reader experience depends on contextual glosses. The filter is future-safe infrastructure and changes no real Greek occurrence-gloss presentation in this release. It creates no empty **In this verse** section: the section is emitted only when a nonempty, learner-facing Greek contextual value adds meaning beyond the lexical gloss. No Swanson sense was imported as occurrence data, and no contextual dataset was created.

The acceptance review found that the first generic implementation also ran against Hebrew occurrence glosses. That would have replaced the existing Hebrew Word Page field and could suppress a value already supplied by the Hebrew interlinear source. The final implementation is Greek-only: Hebrew keeps its prior **Contextual occurrence gloss** field and receives neither the Greek comparison rule nor the **In this verse** presentation. Hebrew corpus data and contextual source behavior are unchanged.

## Learner-facing consistency and data safety

The correction and unavailable-state guard live in the one shared gloss resolver. Learn, Daily Practice, English-first cards, Reader Word Details, Word Page, Search, Custom Decks, and Needs attention therefore resolve the same standard presentation. English-first remains lexical-only and does not expose a Greek answer before reveal.

Personal behavior is unchanged:

- Standard uses the corrected PP standard gloss.
- Add appends a personal gloss to the corrected standard presentation.
- Use replaces the study answer with the personal gloss as before.

No SRS history, mastery state, due date, learning status, personal gloss, Reader location, persisted schema, biblical corpus file, or `vocab_all.json` record changed. No migration is required.

## Deferred review

The audit retains 1,679 semantic items as `NEEDS_HUMAN_REVIEW`, including the unresolved lower-frequency mapped corpus, and 98 PP mapping cases without a safe dictionary mapping. The reverse audit retains 257 missing PP entries, 492 variant-only entries, three possible PP duplicates, and two ambiguous entries. These are not proposed automatic corrections.

Resolving them responsibly would benefit from an independently provenance- and license-verified distributable Greek lexical source with stable Strong/lemma/homonym mappings. Swanson alone cannot authorize shipped semantic wording.

## Reproduction and validation

Run `SWANSON_AUDIT_SOURCE=/absolute/path/to/private-file npm run greek:audit -- --write` to regenerate the sanitized audit locally. Ordinary `npm run greek:audit` validates the committed report without requiring or distributing the private source.

The audit runs entirely at development time. Runtime loads only the existing compact correction manifest; it performs no corpus-wide comparison, Swanson parsing, or per-card audit work.
