# Product Philosophy

For v5, [Product Bible v5](product-bible-v5.md) is the canonical product document. This file preserves the enduring philosophy behind that Bible and should remain consistent with it.

## Mission

Puritan Parser exists to help people become independent readers of Scripture in Biblical Greek and Hebrew.

The goal is not dependence on the software. The highest success is that a user eventually becomes comfortable reading a printed Greek or Hebrew Bible and only occasionally reaches for Puritan Parser as a trusted companion.

Puritan Parser should never compete with Scripture for the user's attention. Its purpose is to remove obstacles so readers can return to the biblical text with greater confidence.

## Product Vision

Puritan Parser is a quiet companion for reading Scripture in the original languages.

It is not a replacement for reading. It is not trying to become a full Bible software suite. It is not an attention economy product.

The app should answer small questions quickly, support real learning, and then get out of the way.

## Core Principles

### Reading first

Everything serves returning users to Scripture.

### Learn to read, not to use the app

Vocabulary, grammar, parsing, paradigms, flashcards, and study tools exist only to build independent readers.

### Quiet software

Avoid engagement mechanics that compete for attention.

### Pocket companion

Answer questions quickly. Return users to Scripture.

### Independence over dependence

The app should become less necessary as users mature.

### Local first

User data belongs to the user. Local storage, export, and future sync should preserve user ownership rather than hide it behind a service.

### Simple over clever

Prefer obvious workflows and maintainable code over clever abstractions that make future work harder.

### Incremental development

Prefer many proven improvements over giant rewrites.

### Shared before separate

Favor shared architecture over duplicate implementations. Add language-specific behavior only when Greek and Hebrew genuinely need different handling.

### Educational outcomes over engagement metrics

Measure success by increasing reading ability rather than increasing app usage.

## Success

The best session in Puritan Parser is a short one that ends with the user reading Scripture more confidently than before.

The ultimate goal is that users increasingly read printed or digital Greek and Hebrew Bibles directly, consulting Puritan Parser only when they encounter an obstacle.

## Things We Intentionally Avoid

- Feature bloat
- Gamification
- Streak pressure
- Artificial engagement
- Dark patterns
- Social feeds
- Attention-seeking notifications
- Anything that distracts from Scripture
