# Data Attribution

The expanded parsing dataset is generated from openly available morphology projects.

## Greek

- Source: MorphGNT SBLGNT
- Repository: https://github.com/morphgnt/sblgnt
- Citation from project README: Tauber, J. K., ed. (2017) MorphGNT: SBLGNT Edition. Version 6.12 [Data set]. https://github.com/morphgnt/sblgnt DOI: 10.5281/zenodo.376200
- Notes: Morphological parsing and lemmatization are provided under CC-BY-SA. The SBLGNT text itself is subject to the SBLGNT EULA.

## Hebrew

- Source: Open Scriptures Hebrew Bible / Open Scriptures Hebrew Morphology
- Repository: https://github.com/openscriptures/morphhb
- Notes: OSHB/OSHM metadata in the source files identifies the morphology project under Creative Commons Attribution 4.0. The Westminster Leningrad Codex text is identified as public domain in the source metadata.

## Generated File

`vocab_all.json` is generated by:

```sh
npm run data:refresh
```

Downloaded source files are cached locally in `data/source/`, which is intentionally ignored by git.
